# To-do-Zettel am Rand (Wunsch der Entwicklerin: nach der Übergabe durch die Maklerin kleine Listen für die kleinen Schritte).
# Einfach hier ändern. Die Zettel kommen nacheinander; ist einer abgehakt, gleitet der nächste herein.
#
# Aufbau:
#   == Überschrift              beginnt einen Zettel
#   kennung | Text | Taste      eine Aufgabe; die Taste ist freiwillig (Name der Eingabe-Aktion, z. B. interact = E,
#                               toggle_build_mode = Gestalten, book_take = rechte Maustaste, book_place = linke Maustaste,
#                               open_menu = Menü)
#   mehrere Tasten mit Komma: build_item_prev,build_item_next (Mausrad = build_rotate)
# Kennungen (woran das Spiel merkt, dass es erledigt ist):
#   tablet         Tablet auf der Theke geöffnet          shelf_ordered  ein Bücherregal gekauft
#   unpack         einen Lieferkarton ausgepackt          shelf_placed   ein Bücherregal steht im Laden
#   build_open     Gestaltungsmodus geöffnet              build_selected im Gestaltungsmodus etwas gewählt
#   build_close    Gestaltungsmodus wieder geschlossen    furniture_placed  etwas aufgestellt
#   crate_book     ein Buch aus einer Bücherkiste genommen
#   shelved        Bücher stehen im Regal                 open_sign      das Schild zeigt „Geöffnet“
#   guest_waiting  ein Gast hat an der Theke geklingelt   desk_open      „Bedienen“ an der Theke
#   card_read      Ausweis im Kartenleser                 books_scanned  alle Bücher gescannt
#   guest_served   einen Gast an der Theke bedient        talked         mit jemandem geredet
#   sat_down       sich hingesetzt                        slept          im Hinterzimmer geschlafen
#   order          etwas bestellt                         wish           einen Wunsch erfüllt
# Zeilen mit # sind Notizen.

== Ein Regal für die Bücher
tablet | Das Tablet auf der Theke öffnen | interact
shelf_ordered | Bei „Nest & Nook“ ein Bücherregal kaufen
unpack | Den Karton draußen vor der Tür auspacken | interact

== Das Regal aufstellen
build_open | Den Gestaltungsmodus öffnen | toggle_build_mode
build_selected | Unten in der Leiste das Regal wählen | build_item_prev,build_item_next
shelf_placed | Mit Linksklick hinstellen – das Mausrad dreht es | build_place,build_rotate
build_close | Den Gestaltungsmodus wieder schließen | toggle_build_mode

== Bücher einräumen
crate_book | Ein Buch aus einer Kiste unter der Theke nehmen | book_take
shelved | Am Regal Linksklick – halten räumt alle Bücher aus der Hand ein | book_place

== Die Tür auf!
open_sign | Draußen das Türschild auf „Geöffnet“ drehen | interact
guest_waiting | Warten, bis ein Gast an der Theke klingelt
desk_open | Hinter die Theke gehen und „Bedienen“ | interact
guest_served | Ausweis, Bücher und Tüte nacheinander anklicken | book_place

== Ankommen in der Straße
talked | Mit jemandem plaudern | interact
sat_down | Im Sessel ein Weilchen sitzen | interact
slept | Abends im Hinterzimmer schlafen gehen
