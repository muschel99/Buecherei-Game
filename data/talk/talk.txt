# So ist diese Datei aufgebaut:
#   == name             beginnt einen Abschnitt: gruss, wieder (Gruß, wenn man eben schon mit derselben Figur geredet hat),
#                       plaudern, drinnen (Gäste in der Bücherei erzählen von Büchern und dem Laden), frage, tschuess,
#                       vertraut (Stammgäste, mit denen man
#                       befreundet ist, erzählen Persönlicheres); Wünsche der Gäste in der Bücherei: wunsch ({wunsch} wird
#                       durch das ersetzt, was der Gast sucht – z. B. „einen spannenden Krimi“, je Genre in
#                       data/talk/genre_wishes.txt; {genre} = nur der Name des Genres), wunsch_ja / wunsch_nein (Antwort des
#                       Gasts), wunsch_wartet, wunsch_danke
#   Text …              ein Satz (eine Zeile = eine Sprechblase)
#   @morgen Text …      gilt nur zu dieser Tageszeit: @morgen (5–11 Uhr), @mittag (11–17), @abend (17–22), @nacht (22–5)
#   > Antwort | Satz    nur bei „frage“: eine Antwort der Spielfigur (zum Anklicken) und was der Gast darauf sagt
#   Satz // Satz        eine kleine Geschichte über mehrere Sprechblasen (geht in allen Abschnitten außer „frage“)
# Was eben gesagt wurde, kommt eine Weile nicht wieder – je mehr Sätze ein Abschnitt hat, desto abwechslungsreicher.
# Zeilen, die mit # beginnen, sind Notizen. Ein Gespräch: ein Gruß, ein bis zwei Sätze zum Plaudern, ab und zu eine Frage
# mit zwei, drei Antworten (keine ist falsch), dann der Abschied.
